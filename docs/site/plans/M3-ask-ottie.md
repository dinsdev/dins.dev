# M3 Ask Ottie Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

Status: Proposed (plan only, 2026-10-21). Task 2.13 in `docs/TASKS.md`. Branch at build time: `feat/m3-ask-ottie`.

**Goal:** Ask Ottie, a small and well-evaluated RAG system on dins.dev: a Python build that turns the approved library and published pages into one binary index, a Worker endpoint that searches it and streams short, cited answers from Claude Haiku inside a hard daily budget, a Svelte island that shows the answer and how it was made, and evals that hold it to the PRD bars.

**Architecture:** `rag/` (Python, uv) chunks Markdown and MDX by heading, embeds chunks with the open bge-m3 weights on Din's machine, quantizes them to int8 and writes `site/public/ask/index-v1.bin` together with a BM25 keyword index in a documented little-endian layout. The built index is committed, and CI only checks that it is fresh (no model download in CI). The Worker reads the index through the `ASSETS` binding into typed-array views once per isolate, embeds the question with bge-m3 on Workers AI, runs hybrid search (cosine plus BM25, fused by reciprocal rank), and takes a canned path (don't know, declined, redirect, resting) without calling the model whenever it can. Otherwise it reserves budget in D1 with one atomic statement, streams from an `AnswerProvider` (a fake or Anthropic) as NDJSON, settles the real cost and writes the anonymous log. The island renders plain text through a tiny formatter that never produces HTML.

**Tech Stack:** Python 3.12 with uv, pydantic 2.14, PyYAML 6.0, numpy 2.5, sentence-transformers 6.1 (optional `embed` extra), anthropic 1.17 (optional `evals` extra), pytest, Ruff. TypeScript 6.0, Astro 7.4 with @astrojs/cloudflare 14.4, Svelte 5.57, Vitest 4.1 with the Cloudflare Workers integration, Playwright 1.64 with @axe-core/playwright, @anthropic-ai/sdk 0.137, tsx 4.23 and yaml 2.x for scripts, wrangler 4.151, D1, Workers AI (`@cf/baai/bge-m3`), Turnstile, the Workers rate limiting binding, Cron Triggers.

**Spec:** `docs/site/PRD.md` sections 2 (library), 3 (Ask Ottie) and 6 (quality); `docs/site/PLAN.md` M3; decisions in `docs/WORK_LEDGER.md` (2026-10-21 entries); voice in `docs/BRAND.md`.

## Global Constraints

Every task's requirements include these lines.

- Answers capped at about 350 tokens (hard `max_tokens: 400`, the prompt asks for at most 120 words); questions at most 300 characters; the last 3 turns kept.
- Daily budget about $1 in the Worker (`ASK_DAILY_BUDGET_USD`, default `"1"`), enforced atomically in D1 before any model call; a $100 hard limit on the Anthropic production workspace and about $5 on the eval workspace (set by Din, see M5).
- Retrieval returns the top 6 chunks, filtered to one project on project pages.
- If nothing scores high enough, Ottie answers "I don't know that one. Din would, here's how to ask." **without calling the model**. Ottie never guesses.
- No tools and no side effects in the model call. Answers render as plain text with simple formatting, never raw HTML (no `{@html}` anywhere in Ask Ottie).
- Resting mode when the API is down or the budget is spent: best-matching pages as links plus Din's contact links. Keyword-only search when Workers AI is down.
- Anonymous question log: question, sources used, scores, thumbs up or down, no IP address, no cookies, kept 30 days, deleted by a nightly cron.
- Site builds never call the model. Suggested answers are generated by a script, reviewed by Din in a PR and served as static text.
- Two answer backends behind one interface: the fake for tests, local work and preview deploys; Anthropic for live checks and production.
- Free Workers plan: about 10 ms CPU per request, 50 subrequests, so no JSON parsing of vectors at request time.
- CI fails on an unapproved library entry or a deny-list topic (visa status, finances, personal life). Only Din sets `approved_on`.
- Eval bars (starting, revisit after the first baseline): recall@6 at least 0.9, faithfulness at least 0.95, 100 percent correct refusals on the deny-list, answers in the question's language. Retrieval evals on every PR; answer evals on manual trigger with the eval key; Haiku judges routine runs, Sonnet judges release runs.
- Ottie talks about Din, never as Din; English, and French when asked in French. Refer to Din by name, never with pronouns.
- Sample library entries are clearly marked samples (`sample: true`, topic starting "Sample:") and state only true facts about the site, never invented facts about Din.
- Writing style everywhere (code comments, UI strings, docs, commits): no em dashes, no en dashes as separators, no AI buzzwords. Commits use Conventional Commits with no attribution lines.
- Pin dependencies to minor versions. Stop and ask Din before downloading the bge-m3 weights (about 2.3 GB), before any step that spends API money, before creating Cloudflare resources, pushing, opening PRs or deploying.

## Review Focus

Inputs the spec implies but that are easy to miss. Each has a test in the task named.

1. **Short follow-up questions** ("and what stack?") after a first question: retrieval would miss without context. Expected: the previous question is added to the retrieval query. Test: Task 25 (`pipeline.test.ts`, "follow-up uses the previous question").
2. **A visitor closing the tab mid-answer:** the stream aborts. Expected: the reservation stays charged (never under-counted), the log row is still written, nothing throws. Test: Task 27 ("client disconnect keeps the reservation").
3. **Two tabs at the budget edge:** concurrent questions when one reservation is left. Expected: exactly the affordable number reserve, the rest rest. Test: Task 15 ("concurrent reservations never overshoot").
4. **Model output with HTML, Markdown links or a fake citation:** `<script>`, `[click](https://evil)`, `[9]` with 6 sources. Expected: shown as literal text, no external link, no chip for `[9]`. Test: Task 29 (`format.test.ts`).
5. **Questions that tokenize to nothing or to accents only:** emoji, "?", "Qu'est-ce que c'est ?". Expected: keyword search returns no hits and the don't-know path runs; French accents tokenize the same in Python and TypeScript. Tests: Task 4 (shared tokenizer fixture), Task 19 (`search.test.ts`, "empty query").

from __future__ import annotations

import tomllib
from dataclasses import dataclass
from pathlib import Path

RAG_DIR = Path(__file__).resolve().parents[2]


@dataclass(frozen=True)
class Paths:
    library: Path
    projects: Path
    writing: Path
    suggested: Path
    stopwords: Path
    denylist: Path
    index_out: Path
    query_embeddings: Path
    golden: Path
    adversarial: Path


@dataclass(frozen=True)
class Chunking:
    max_chars: int
    min_chars: int


@dataclass(frozen=True)
class Search:
    top_k: int
    rrf_k: int
    bm25_k1: float
    bm25_b: float
    dense_threshold: float
    bm25_threshold: float
    keyword_coverage: float


@dataclass(frozen=True)
class EmbedderCfg:
    model: str
    revision: str
    pooling: str
    dim: int


@dataclass(frozen=True)
class Settings:
    root: Path
    paths: Paths
    chunking: Chunking
    search: Search
    embedder: EmbedderCfg
    scan_globs: tuple[str, ...]
    source_file: Path


def load_settings(path: Path | None = None) -> Settings:
    path = (path or RAG_DIR / "rag.toml").resolve()
    raw = tomllib.loads(path.read_text(encoding="utf-8"))
    p = dict(raw["paths"])
    root = (path.parent / p.pop("repo_root")).resolve()
    return Settings(
        root=root,
        paths=Paths(**{k: (root / v).resolve() for k, v in p.items()}),
        chunking=Chunking(**raw["chunking"]),
        search=Search(**raw["search"]),
        embedder=EmbedderCfg(**raw["embedder"]),
        scan_globs=tuple(raw["checks"]["scan_globs"]),
        source_file=path,
    )
```

`rag/src/ottie_rag/cli.py` (later tasks add subcommands to `_build_parser` and `_COMMANDS`):

```python
from __future__ import annotations

import argparse
import sys
from collections.abc import Callable
from pathlib import Path

from .settings import Settings, load_settings


def _cmd_settings(args: argparse.Namespace, settings: Settings) -> int:
    print(f"root: {settings.root}")
    for name, value in vars(settings.paths).items():
        print(f"{name}: {value}")
    return 0


_COMMANDS: dict[str, Callable[[argparse.Namespace, Settings], int]] = {
    "settings": _cmd_settings,
}


def _build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="ottie-rag", description="Ask Ottie build, checks and evals")
    parser.add_argument("--settings", type=Path, default=None, help="path to rag.toml")
    sub = parser.add_subparsers(dest="command", required=True)
    sub.add_parser("settings", help="print resolved paths")
    return parser


def main(argv: list[str] | None = None) -> int:
    args = _build_parser().parse_args(argv)
    settings = load_settings(args.settings)
    return _COMMANDS[args.command](args, settings)


if __name__ == "__main__":
    sys.exit(main())
```

from __future__ import annotations

import yaml


def split_frontmatter(text: str) -> tuple[dict, str]:
    """Split a leading YAML block fenced by '---' lines from the body."""
    if not text.startswith("---\n"):
        return {}, text
    end = text.find("\n---\n", 4)
    if end == -1:
        if text.endswith("\n---"):
            end = len(text) - 4
        else:
            raise ValueError("unclosed frontmatter block")
    meta = yaml.safe_load(text[4:end]) or {}
    if not isinstance(meta, dict):
        raise ValueError("frontmatter must be a mapping")
    return meta, text[end + 5 :]

from pydantic import BaseModel, ConfigDict, Field

class LibraryFrontmatter(BaseModel):

class PageFrontmatter(BaseModel):
    model_config = ConfigDict(extra="ignore")
    title: str = Field(min_length=1)
    status: Literal["draft", "published"]
    language: Language = "en"
    project: str | None = None


@dataclass(frozen=True)
class Document:
    source: str
    url: str | None
    kind: Kind
    title: str
    project: str | None
    language: Language
    body: str
    sample: bool
    approved_on: date | None

class LibraryFile:
    path: Path
    source: str
    meta: LibraryFrontmatter
    body: str


def _source(settings: Settings, path: Path) -> str:
    return path.resolve().relative_to(settings.root).as_posix()


def _files(folder: Path, *suffixes: str) -> list[Path]:
    if not folder.exists():
        return []
    return sorted(p for p in folder.iterdir() if p.is_file() and p.suffix in suffixes)


def load_library_files(settings: Settings) -> list[LibraryFile]:
    out = []
    for path in _files(settings.paths.library, ".md"):
        meta, body = split_frontmatter(path.read_text(encoding="utf-8"))
        out.append(LibraryFile(path, _source(settings, path), LibraryFrontmatter.model_validate(meta), body))
    return out


def _pages(settings: Settings, folder: Path, kind: Kind, prefix: str) -> list[Document]:
    docs = []
    for path in _files(folder, ".md", ".mdx"):
        meta, body = split_frontmatter(path.read_text(encoding="utf-8"))
        fm = PageFrontmatter.model_validate(meta)
        if fm.status != "published":
            continue
        slug = path.stem
        project = slug if kind == "project" else fm.project
        docs.append(Document(_source(settings, path), f"{prefix}/{slug}", kind, fm.title, project, fm.language, body, False, None))
    return docs


def load_documents(settings: Settings) -> list[Document]:
    docs = [
        Document(f.source, None, "library", f.meta.topic, f.meta.project, f.meta.language, f.body, f.meta.sample, f.meta.approved_on)
        for f in load_library_files(settings)
        if f.meta.approved_on is not None or f.meta.sample
    ]
    docs += _pages(settings, settings.paths.projects, "project", "/work")
    docs += _pages(settings, settings.paths.writing, "writing", "/writing")

```python
from __future__ import annotations

import re
from dataclasses import dataclass


@dataclass(frozen=True)
class Section:
    heading: str
    text: str


_FENCE = re.compile(r"^\s*(```|~~~)")
_HEADING = re.compile(r"^(#{1,6})\s+(.+?)\s*#*\s*$")
_IMPORT_EXPORT = re.compile(r"^(import|export)\s")
_JSX_SELF = re.compile(r"<[A-Z][\w.]*\b[^>]*/>")
_JSX_TAG = re.compile(r"</?[A-Z][\w.]*\b[^>]*>")
_HTML_TAG = re.compile(r"</?[a-z][^>]*>")
_HTML_COMMENT = re.compile(r"<!--.*?-->", re.S)
_MDX_COMMENT = re.compile(r"\{/\*.*?\*/\}", re.S)
_IMAGE = re.compile(r"!\[([^\]]*)\]\([^)]*\)")
_LINK = re.compile(r"\[([^\]]+)\]\([^)]*\)")
_STRONG = re.compile(r"(\*\*|__)(.+?)\1")
_EM = re.compile(r"(?<![\w*_])[*_](\S(?:.*?\S)?)[*_](?![\w*_])")
_CODE = re.compile(r"`([^`]+)`")
_QUOTE = re.compile(r"^\s*>\s?")
_LIST = re.compile(r"^\s*(?:[-*+]|\d+[.)])\s+")
_SPACES = re.compile(r"\s+")


def clean_inline(text: str) -> str:
    text = _IMAGE.sub(r"\1", text)
    text = _LINK.sub(r"\1", text)
    text = _CODE.sub(r"\1", text)
    text = _STRONG.sub(r"\2", text)
    text = _EM.sub(r"\1", text)
    text = _HTML_TAG.sub("", text)
    return _SPACES.sub(" ", text).strip()


def mdx_to_sections(body: str) -> list[Section]:
    body = _MDX_COMMENT.sub("", _HTML_COMMENT.sub("", body))
    sections: list[Section] = []
    paras: list[str] = []
    buf: list[str] = []
    h2: str | None = None
    heading = ""
    in_fence = False

    def flush_para() -> None:
        if buf:
            paras.append(" ".join(buf))
            buf.clear()

    def flush_section() -> None:
        flush_para()
        if paras:
            sections.append(Section(heading, "\n\n".join(paras)))
            paras.clear()

    for raw in body.splitlines():
        if _FENCE.match(raw):
            in_fence = not in_fence
            flush_para()
            continue
        if in_fence or _IMPORT_EXPORT.match(raw):
            continue
        m = _HEADING.match(raw)
        if m:
            level, title = len(m.group(1)), clean_inline(m.group(2))
            if level == 1:
                flush_para()
                continue
            flush_section()
            if level == 2 or h2 is None:
                h2 = title
                heading = title
            else:
                heading = f"{h2} > {title}"
            continue
        line = _JSX_TAG.sub("", _JSX_SELF.sub("", raw))
        if not line.strip():
            flush_para()
            continue
        is_item = bool(_LIST.match(line))
        text = clean_inline(_LIST.sub("", _QUOTE.sub("", line)))
        if not text:
            continue
        if is_item:
            flush_para()
            buf.append(f"- {text}")
            flush_para()
        else:
            buf.append(text)
    flush_section()
    return sections
```

```python
from __future__ import annotations

import re
import unicodedata
from dataclasses import dataclass

from .corpus import Document
from .settings import Settings
from .textclean import Section, mdx_to_sections


@dataclass(frozen=True)
class Chunk:
    id: str
    source: str
    url: str | None
    kind: str
    project: str | None
    language: str
    title: str
    heading: str
    text: str
    sample: bool


_SENTENCE = re.compile(r"(?<=[.!?])\s+")


def slugify(text: str) -> str:
    folded = "".join(c for c in unicodedata.normalize("NFKD", text.lower()) if not unicodedata.category(c).startswith("M"))
    return re.sub(r"[^a-z0-9]+", "-", folded).strip("-")


def _pack(parts: list[str], max_chars: int, joiner: str) -> list[str]:
    out: list[str] = []
    cur = ""
    for part in parts:
        if len(part) > max_chars:
            if cur:
                out.append(cur)
                cur = ""
            out.extend(part[i : i + max_chars] for i in range(0, len(part), max_chars))
            continue
        candidate = f"{cur}{joiner}{part}" if cur else part
        if len(candidate) <= max_chars:
            cur = candidate
        else:
            out.append(cur)
            cur = part
    if cur:
        out.append(cur)
    return out


def _split(text: str, max_chars: int) -> list[str]:
    if len(text) <= max_chars:
        return [text]
    pieces: list[str] = []
    for para in text.split("\n\n"):
        pieces.extend([para] if len(para) <= max_chars else _pack(_SENTENCE.split(para), max_chars, " "))
    return _pack(pieces, max_chars, "\n\n")


def _merge_small(sections: list[Section], min_chars: int) -> list[Section]:
    merged: list[Section] = []
    for s in sections:
        if merged and len(s.text) < min_chars:
            prev = merged[-1]
            label = f"{s.heading}: " if s.heading and s.heading != prev.heading else ""
            merged[-1] = Section(prev.heading, f"{prev.text}\n\n{label}{s.text}")
        else:
            merged.append(s)
    return merged


def chunk_document(doc: Document, max_chars: int, min_chars: int) -> list[Chunk]:
    chunks: list[Chunk] = []
    counts: dict[str, int] = {}
    for s in _merge_small(mdx_to_sections(doc.body), min_chars):
        key = slugify(s.heading) or "intro"
        for piece in _split(s.text, max_chars):
            n = counts.get(key, 0)
            counts[key] = n + 1
            chunks.append(Chunk(f"{doc.source}#{key}-{n}", doc.source, doc.url, doc.kind, doc.project, doc.language, doc.title, s.heading, piece, doc.sample))
    return chunks


def chunk_corpus(docs: list[Document], settings: Settings) -> list[Chunk]:
    out: list[Chunk] = []
    for d in sorted(docs, key=lambda d: d.source):
        out.extend(chunk_document(d, settings.chunking.max_chars, settings.chunking.min_chars))
    return out


def chunk_index_text(chunk: Chunk) -> str:
    return "\n".join(part for part in (chunk.title, chunk.heading, chunk.text) if part)
```

```python
from __future__ import annotations

import hashlib
import json
import re
import unicodedata
from functools import cache
from pathlib import Path

_STOPWORDS_FILE = Path(__file__).resolve().parents[3] / "site/src/lib/ask/stopwords.json"
_WORD = re.compile(r"[a-z0-9]+")
_SPACES = re.compile(r"\s+")


@cache
def _stopwords() -> frozenset[str]:
    return frozenset(json.loads(_STOPWORDS_FILE.read_text(encoding="utf-8"))["words"])


def fold(text: str) -> str:
    decomposed = unicodedata.normalize("NFKD", text.lower())
    return "".join(c for c in decomposed if not unicodedata.category(c).startswith("M"))


def tokenize(text: str, keep_stopwords: bool = False) -> list[str]:
    stop = _stopwords()
    return [w for w in _WORD.findall(fold(text)) if len(w) >= 2 and (keep_stopwords or w not in stop)]


def fnv1a32(s: str) -> int:
    h = 0x811C9DC5
    for b in s.encode("utf-8"):
        h ^= b
        h = (h * 0x01000193) & 0xFFFFFFFF
    return h


def normalize_question(q: str) -> str:
    return _SPACES.sub(" ", unicodedata.normalize("NFC", q)).strip()


def question_key(q: str) -> bytes:
    return hashlib.sha256(normalize_question(q).encode("utf-8")).digest()

```python
from __future__ import annotations

from collections import Counter
from dataclasses import dataclass

import numpy as np

from .textnorm import fnv1a32


@dataclass(frozen=True)
class KeywordIndex:
    term_hashes: np.ndarray
    starts: np.ndarray
    post_ids: np.ndarray
    post_tf: np.ndarray
    doc_len: np.ndarray
    avgdl: float


def build_keyword_index(token_lists: list[list[str]]) -> KeywordIndex:
    postings: dict[int, dict[int, int]] = {}
    owner: dict[int, str] = {}
    for doc_id, tokens in enumerate(token_lists):
        for term, tf in Counter(tokens).items():
            h = fnv1a32(term)
            first = owner.setdefault(h, term)
            if first != term:
                raise ValueError(f"term hash collision: {first!r} and {term!r}")
            postings.setdefault(h, {})[doc_id] = min(tf, 65535)
    hashes = sorted(postings)
    starts, ids, tfs = [0], [], []
    for h in hashes:
        for doc_id in sorted(postings[h]):
            ids.append(doc_id)
            tfs.append(postings[h][doc_id])
        starts.append(len(ids))
    doc_len = np.array([len(t) for t in token_lists], dtype=np.uint32)
    return KeywordIndex(
        term_hashes=np.array(hashes, dtype=np.uint32),
        starts=np.array(starts, dtype=np.uint32),
        post_ids=np.array(ids, dtype=np.uint32),
        post_tf=np.array(tfs, dtype=np.uint16),
        doc_len=doc_len,
        avgdl=float(doc_len.mean()) if len(token_lists) else 0.0,
    )
```

```python
from __future__ import annotations

import hashlib
from typing import Protocol

import numpy as np

from .settings import EmbedderCfg
from .textnorm import tokenize


class Embedder(Protocol):
    id: str
    dim: int

    def embed(self, texts: list[str]) -> np.ndarray: ...


def _token_vector(token: str, dim: int) -> np.ndarray:
    values: list[float] = []
    counter = 0
    while len(values) < dim:
        digest = hashlib.sha256(f"{token}:{counter}".encode()).digest()
        counter += 1
        values.extend(int.from_bytes(digest[j : j + 4], "little") / 0xFFFFFFFF * 2 - 1 for j in range(0, 32, 4))
    return np.array(values[:dim], dtype=np.float64)


class HashEmbedder:
    """Deterministic bag-of-words vectors for tests. Not a semantic model."""

    def __init__(self, dim: int = 16) -> None:
        self.dim = dim
        self.id = f"hash-v1:{dim}"

    def embed(self, texts: list[str]) -> np.ndarray:
        out = np.zeros((len(texts), self.dim), dtype=np.float32)
        for i, text in enumerate(texts):
            v = np.zeros(self.dim, dtype=np.float64)
            for token in tokenize(text):
                v += _token_vector(token, self.dim)
            norm = float(np.linalg.norm(v))
            if norm > 0:
                out[i] = (v / norm).astype(np.float32)
        return out


class BgeM3Embedder:
    """bge-m3 dense embeddings from the open weights, CPU only."""

    FILES = [
        "config.json",
        "pytorch_model.bin",
        "tokenizer.json",
        "tokenizer_config.json",
        "special_tokens_map.json",
        "sentencepiece.bpe.model",
        "modules.json",
        "sentence_bert_config.json",
        "config_sentence_transformers.json",
        "1_Pooling/config.json",
    ]

    def __init__(self, cfg: EmbedderCfg) -> None:
        from huggingface_hub import snapshot_download
        from sentence_transformers import SentenceTransformer

        path = snapshot_download(cfg.model, revision=cfg.revision, allow_patterns=self.FILES)
        self.model = SentenceTransformer(path, device="cpu")
        if cfg.pooling == "mean":
            from sentence_transformers.models import Pooling

            self.model._modules["1"] = Pooling(cfg.dim, pooling_mode="mean")
        elif cfg.pooling != "cls":
            raise ValueError(f"unknown pooling {cfg.pooling!r}")
        self.model.max_seq_length = 1024
        self.dim = cfg.dim
        self.id = f"{cfg.model}@{cfg.revision}:{cfg.pooling}"

    def embed(self, texts: list[str]) -> np.ndarray:
        vectors = self.model.encode(texts, batch_size=8, normalize_embeddings=True, convert_to_numpy=True, show_progress_bar=len(texts) > 32)
        return np.asarray(vectors, dtype=np.float32)


def make_embedder(cfg: EmbedderCfg) -> Embedder:
    if cfg.model == "hash":
        return HashEmbedder(cfg.dim)
    return BgeM3Embedder(cfg)


def quantize_int8(vectors: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    v = np.asarray(vectors, dtype=np.float32)
    if v.size == 0:
        return v.astype(np.int8), np.zeros(len(v), dtype=np.float32)
    peak = np.abs(v).max(axis=1)
    scales = np.where(peak > 0, peak / 127.0, 1.0).astype(np.float32)
    q = np.clip(np.rint(v / scales[:, None]), -127, 127).astype(np.int8)
    return q, scales
```

# Ask Ottie index format, version 1

`site/public/ask/index-v1.bin` is written by `rag/` (`ottie_rag.index_format.write_index`) and read by the Worker (`site/src/lib/ask/index-format.ts`). Everything is little-endian. A reader must reject a file whose magic, version or total length does not match.

## Header (96 bytes)

| Offset | Size | Type | Field |
|---:|---:|---|---|
| 0 | 4 | ASCII | magic `OTIX` |
| 4 | 2 | u16 | format version, `1` |
| 6 | 2 | u16 | vector dimension `D` |
| 8 | 4 | u32 | chunk count `N` |
| 12 | 4 | u32 | term count `T` |
| 16 | 4 | u32 | posting count `P` |
| 20 | 4 | u32 | string table bytes `S` |
| 24 | 4 | u32 | flags (bit 0: the index contains sample entries) |
| 28 | 4 | f32 | BM25 average document length |
| 32 | 4 | f32 | dense threshold (don't-know gate, hybrid mode) |
| 36 | 4 | f32 | BM25 threshold (don't-know gate, keyword mode) |
| 40 | 4 | f32 | minimum query-term coverage (keyword mode) |
| 44 | 4 | u32 | reciprocal rank fusion constant `k` |
| 48 | 4 | f32 | BM25 `k1` |
| 52 | 4 | f32 | BM25 `b` |
| 56 | 4 | u32 | project list offset in the string table |
| 60 | 4 | u32 | project list length in bytes |
| 64 | 32 | bytes | sha256 of the corpus (chunks, chunking settings, embedder id) |

## Sections

Offsets follow from the counts, so there is no offset table. `align4(x)` rounds up to a multiple of 4.

| Section | Offset | Content |
|---|---|---|
| vectors | 96 | `N × D` int8, row-major. Chunk vectors are L2-normalized before quantization. |
| scales | `align4(96 + N·D)` | `N` f32. Cosine of chunk `i` with a unit query `q` is `scale[i] · Σ vector[i][k] · q[k]`. |
| records | scales + `4N` | `N` records of 24 bytes (below). |
| term hashes | records + `24N` | `T` u32 FNV-1a hashes of terms, ascending. |
| term starts | term hashes + `4T` | `T + 1` u32: postings of term `t` are `[start[t], start[t+1])`. |
| posting chunk ids | term starts + `4(T+1)` | `P` u32 chunk indexes, ascending within each term. |
| posting term frequencies | posting ids + `4P` | `P` u16. |
| strings | `align4(tf + 2P)` | `S` bytes of UTF-8. Total file length is `strings + S`. |

Record (24 bytes): `u32 text_off`, `u32 text_len`, `u32 meta_off`, `u32 meta_len`, `u16 project_id` (0 = none, otherwise 1 + the index in the project list), `u8 kind` (0 library, 1 project, 2 writing), `u8 language` (0 en, 1 fr), `u32 doc_len` (BM25 token count). The meta string is `title`, `heading`, `url` (empty when none) and `source`, separated by U+001F. The project list is project slugs separated by U+001F, sorted.

## Search algorithm v1 (both readers implement it the same way)

1. Candidates: all chunks, or only chunks whose project is the requested project. An unknown project has no candidates.
2. Query terms: the unique tokens of the retrieval query (tokenizer in `site/src/lib/ask/text.ts` and `rag/src/ottie_rag/textnorm.py`), sorted.
3. BM25 per candidate with `idf = ln(1 + (N - df + 0.5) / (df + 0.5))` and the header's `k1`, `b`, average length.
4. Hybrid mode (a query vector is present): dense cosine as above. Rank candidates by dense (top 50) and by BM25 among chunks with a score above 0 (top 50). Fused score `Σ 1 / (k + rank)`. Order by fused, then dense, then chunk index. Answerable when the best dense score among candidates is at least the dense threshold.
5. Keyword mode (no vector, for example Workers AI is down): order by BM25 among chunks with a score above 0, then chunk index. Answerable when the best chunk's BM25 is at least the BM25 threshold and it matches at least the coverage fraction of the query terms.
6. Return the top 6.

## Query-embedding cache (`rag/evals/query-embeddings.bin`)

| Offset | Size | Type | Field |
|---:|---:|---|---|
| 0 | 4 | ASCII | magic `OTQE` |
| 4 | 2 | u16 | version `1` |
| 6 | 2 | u16 | dimension `D` |
| 8 | 4 | u32 | count `C` |
| 12 | 4 | u32 | reserved, 0 |
| 16 | `C × (32 + 4D)` | | records sorted by key: 32-byte sha256 of the normalized retrieval query, then `D` f32 |

The retrieval query is the question, or the previous question, a newline and the question for follow-ups.

```python
from __future__ import annotations

import struct
from dataclasses import dataclass

import numpy as np

from .keyword import KeywordIndex
from .textnorm import question_key

MAGIC = b"OTIX"
VERSION = 1
HEADER_BYTES = 96
RECORD_BYTES = 24
KINDS = ("library", "project", "writing")
LANGS = ("en", "fr")
FLAG_SAMPLES = 1
SEP = "\x1f"
_HEADER = struct.Struct("<4sHHIIIIIffffIffII32s")
_RECORD = struct.Struct("<IIIIHBBI")
_PARAMS_AT = 32  # dense_threshold, bm25_threshold, keyword_coverage (3 x f32) start here
assert _HEADER.size == HEADER_BYTES and _RECORD.size == RECORD_BYTES

QMAGIC = b"OTQE"
_QHEADER = struct.Struct("<4sHHII")


class IndexFormatError(ValueError):
    pass


@dataclass(frozen=True)
class IndexParams:
    avgdl: float
    dense_threshold: float
    bm25_threshold: float
    keyword_coverage: float
    rrf_k: int
    bm25_k1: float
    bm25_b: float


@dataclass(frozen=True)
class ChunkRecord:
    text: str
    title: str
    heading: str
    url: str | None
    source: str
    project: str | None
    kind: str
    language: str
    doc_len: int


@dataclass(frozen=True)
class IndexData:
    version: int
    dim: int
    flags: int
    corpus_hash: bytes
    params: IndexParams
    vectors: np.ndarray
    scales: np.ndarray
    records: list[ChunkRecord]
    projects: list[str]
    term_hashes: np.ndarray
    starts: np.ndarray
    post_ids: np.ndarray
    post_tf: np.ndarray

    @property
    def count(self) -> int:
        return len(self.records)


def _align4(n: int) -> int:
    return (n + 3) & ~3


def layout(n: int, d: int, t: int, p: int) -> dict[str, int]:
    o = {"vectors": HEADER_BYTES}
    o["scales"] = _align4(o["vectors"] + n * d)
    o["records"] = o["scales"] + 4 * n
    o["term_hashes"] = o["records"] + RECORD_BYTES * n
    o["starts"] = o["term_hashes"] + 4 * t
    o["post_ids"] = o["starts"] + 4 * (t + 1)
    o["post_tf"] = o["post_ids"] + 4 * p
    o["strings"] = _align4(o["post_tf"] + 2 * p)
    return o


def write_index(*, vectors: np.ndarray, scales: np.ndarray, records: list[ChunkRecord], keyword: KeywordIndex, params: IndexParams, corpus_hash: bytes, flags: int) -> bytes:
    n = len(records)
    d = int(vectors.shape[1]) if vectors.ndim == 2 else 0
    if vectors.shape[0] != n or len(scales) != n:
        raise ValueError("vectors, scales and records must have the same length")
    if len(corpus_hash) != 32:
        raise ValueError("corpus_hash must be 32 bytes")
    t, p = len(keyword.term_hashes), len(keyword.post_ids)
    projects = sorted({r.project for r in records if r.project})
    strings = bytearray()

    def put(s: str) -> tuple[int, int]:
        b = s.encode("utf-8")
        off = len(strings)
        strings.extend(b)
        return off, len(b)

    proj_off, proj_len = put(SEP.join(projects))
    recs = bytearray()
    for r in records:
        text_off, text_len = put(r.text)
        meta_off, meta_len = put(SEP.join([r.title, r.heading, r.url or "", r.source]))
        pid = projects.index(r.project) + 1 if r.project else 0
        recs += _RECORD.pack(text_off, text_len, meta_off, meta_len, pid, KINDS.index(r.kind), LANGS.index(r.language), r.doc_len)

    o = layout(n, d, t, p)
    buf = bytearray(o["strings"] + len(strings))
    _HEADER.pack_into(
        buf, 0, MAGIC, VERSION, d, n, t, p, len(strings), flags,
        params.avgdl, params.dense_threshold, params.bm25_threshold, params.keyword_coverage,
        params.rrf_k, params.bm25_k1, params.bm25_b, proj_off, proj_len, corpus_hash,
    )
    buf[o["vectors"] : o["vectors"] + n * d] = np.ascontiguousarray(vectors, dtype=np.int8).tobytes()
    buf[o["scales"] : o["scales"] + 4 * n] = np.asarray(scales, dtype="<f4").tobytes()
    buf[o["records"] : o["records"] + len(recs)] = recs
    buf[o["term_hashes"] : o["starts"]] = np.asarray(keyword.term_hashes, dtype="<u4").tobytes()
    buf[o["starts"] : o["post_ids"]] = np.asarray(keyword.starts, dtype="<u4").tobytes()
    buf[o["post_ids"] : o["post_tf"]] = np.asarray(keyword.post_ids, dtype="<u4").tobytes()
    buf[o["post_tf"] : o["post_tf"] + 2 * p] = np.asarray(keyword.post_tf, dtype="<u2").tobytes()
    buf[o["strings"] :] = strings
    return bytes(buf)


def read_index(data: bytes) -> IndexData:
    if len(data) < HEADER_BYTES:
        raise IndexFormatError("index too short")
    (magic, version, d, n, t, p, s, flags, avgdl, dense_t, bm25_t, cov, rrf_k, k1, b, proj_off, proj_len, chash) = _HEADER.unpack_from(data, 0)
    if magic != MAGIC:
        raise IndexFormatError("bad magic")
    if version != VERSION:
        raise IndexFormatError(f"unsupported index version {version}")
    o = layout(n, d, t, p)
    if len(data) != o["strings"] + s:
        raise IndexFormatError(f"index length {len(data)} does not match layout {o['strings'] + s}")
    strings = data[o["strings"] :]

    def text(off: int, length: int) -> str:
        return strings[off : off + length].decode("utf-8")

    projects = text(proj_off, proj_len).split(SEP) if proj_len else []
    records = []
    for i in range(n):
        to, tl, mo, ml, pid, kind, lang, dl = _RECORD.unpack_from(data, o["records"] + i * RECORD_BYTES)
        title, heading, url, source = text(mo, ml).split(SEP)
        records.append(ChunkRecord(text(to, tl), title, heading, url or None, source, projects[pid - 1] if pid else None, KINDS[kind], LANGS[lang], dl))
    return IndexData(
        version=version, dim=d, flags=flags, corpus_hash=chash,
        params=IndexParams(avgdl, dense_t, bm25_t, cov, rrf_k, k1, b),
        vectors=np.frombuffer(data, dtype=np.int8, count=n * d, offset=o["vectors"]).reshape(n, d),
        scales=np.frombuffer(data, dtype="<f4", count=n, offset=o["scales"]),
        records=records, projects=projects,
        term_hashes=np.frombuffer(data, dtype="<u4", count=t, offset=o["term_hashes"]),
        starts=np.frombuffer(data, dtype="<u4", count=t + 1, offset=o["starts"]),
        post_ids=np.frombuffer(data, dtype="<u4", count=p, offset=o["post_ids"]),
        post_tf=np.frombuffer(data, dtype="<u2", count=p, offset=o["post_tf"]),
    )


def rewrite_params(data: bytes, params: IndexParams) -> bytes:
    read_index(data)
    buf = bytearray(data)
    struct.pack_into("<fff", buf, _PARAMS_AT, params.dense_threshold, params.bm25_threshold, params.keyword_coverage)
    struct.pack_into("<I", buf, 44, params.rrf_k)
    struct.pack_into("<ff", buf, 48, params.bm25_k1, params.bm25_b)
    return bytes(buf)


@dataclass(frozen=True)
class QueryCache:
    dim: int
    entries: dict[bytes, np.ndarray]

    def keys(self) -> list[bytes]:
        return sorted(self.entries)

    def get(self, question: str) -> np.ndarray | None:
        return self.entries.get(question_key(question))


def write_query_cache(entries: dict[bytes, np.ndarray], dim: int) -> bytes:
    out = bytearray(_QHEADER.pack(QMAGIC, 1, dim, len(entries), 0))
    for key in sorted(entries):
        vec = np.asarray(entries[key], dtype="<f4")
        if len(key) != 32 or vec.shape != (dim,):
            raise ValueError("bad query cache entry")
        out += key + vec.tobytes()
    return bytes(out)


def read_query_cache(data: bytes) -> QueryCache:
    magic, version, dim, count, _ = _QHEADER.unpack_from(data, 0)
    if magic != QMAGIC or version != 1:
        raise IndexFormatError("bad query cache header")
    size = 32 + 4 * dim
    if len(data) != _QHEADER.size + count * size:
        raise IndexFormatError("query cache length mismatch")
    entries = {}
    for i in range(count):
        at = _QHEADER.size + i * size
        entries[data[at : at + 32]] = np.frombuffer(data, dtype="<f4", count=dim, offset=at + 32).copy()
    return QueryCache(dim, entries)

```python
from __future__ import annotations

import math
from dataclasses import dataclass

import numpy as np

from .index_format import IndexData
from .textnorm import fnv1a32, tokenize

TOP_K = 6
POOL = 50


@dataclass(frozen=True)
class Hit:
    chunk: int
    dense: float | None
    bm25: float
    matched: int
    fused: float


@dataclass(frozen=True)
class SearchResult:
    mode: str
    hits: list[Hit]
    answerable: bool
    top_dense: float | None
    query_terms: int


def _bm25(ix: IndexData, terms: list[str]) -> tuple[list[float], list[int]]:
    n = ix.count
    scores, matched = [0.0] * n, [0] * n
    p = ix.params
    if n == 0 or p.avgdl <= 0:
        return scores, matched
    for term in terms:
        h = fnv1a32(term)
        pos = int(np.searchsorted(ix.term_hashes, h))
        if pos >= len(ix.term_hashes) or int(ix.term_hashes[pos]) != h:
            continue
        start, end = int(ix.starts[pos]), int(ix.starts[pos + 1])
        df = end - start
        idf = math.log(1 + (n - df + 0.5) / (df + 0.5))
        for j in range(start, end):
            d = int(ix.post_ids[j])
            tf = int(ix.post_tf[j])
            dl = ix.records[d].doc_len
            scores[d] += idf * tf * (p.bm25_k1 + 1) / (tf + p.bm25_k1 * (1 - p.bm25_b + p.bm25_b * dl / p.avgdl))
            matched[d] += 1
    return scores, matched


def search(ix: IndexData, qvec: np.ndarray | None, question: str, project: str | None = None, top_k: int = TOP_K) -> SearchResult:
    if project is None:
        cand = list(range(ix.count))
    else:
        cand = [i for i, r in enumerate(ix.records) if r.project == project]
    terms = sorted(set(tokenize(question)))
    bm25, matched = _bm25(ix, terms)

    if qvec is None:
        ranked = sorted((c for c in cand if bm25[c] > 0), key=lambda c: (-bm25[c], c))[:top_k]
        hits = [Hit(c, None, bm25[c], matched[c], bm25[c]) for c in ranked]
        best = hits[0] if hits else None
        answerable = bool(best) and best.bm25 >= ix.params.bm25_threshold and best.matched / max(len(terms), 1) >= ix.params.keyword_coverage
        return SearchResult("keyword", hits, answerable, None, len(terms))

    q = np.asarray(qvec, dtype=np.float32).astype(np.float64)
    if q.shape != (ix.dim,):
        raise ValueError(f"query vector has {q.shape[0]} dims, index has {ix.dim}")
    norm = float(np.sqrt(np.sum(q * q)))
    if norm > 0:
        q = q / norm
    dense = {c: float(ix.vectors[c].astype(np.float64) @ q) * float(ix.scales[c]) for c in cand}
    fused = {c: 0.0 for c in cand}
    for rank, c in enumerate(sorted(cand, key=lambda c: (-dense[c], c))[:POOL], start=1):
        fused[c] += 1.0 / (ix.params.rrf_k + rank)
    for rank, c in enumerate(sorted((c for c in cand if bm25[c] > 0), key=lambda c: (-bm25[c], c))[:POOL], start=1):
        fused[c] += 1.0 / (ix.params.rrf_k + rank)
    ranked = sorted(cand, key=lambda c: (-fused[c], -dense[c], c))[:top_k]
    hits = [Hit(c, dense[c], bm25[c], matched[c], fused[c]) for c in ranked]
    top_dense = max(dense.values()) if dense else None
    answerable = top_dense is not None and top_dense >= ix.params.dense_threshold
    return SearchResult("hybrid", hits, answerable, top_dense, len(terms))

```python
from __future__ import annotations

import hashlib
import json
from dataclasses import asdict

import numpy as np

from .chunking import Chunk, chunk_corpus, chunk_index_text
from .corpus import load_documents
from .embedders import Embedder, quantize_int8
from .index_format import FLAG_SAMPLES, ChunkRecord, IndexParams, read_index, write_index
from .keyword import build_keyword_index
from .settings import Settings
from .textnorm import tokenize

REBUILD_HINT = "Run `pnpm --dir site ask:index` on Din's machine and commit site/public/ask/index-v1.bin and rag/evals/query-embeddings.bin."


def collect_chunks(settings: Settings) -> list[Chunk]:
    return chunk_corpus(load_documents(settings), settings)


def expected_embedder_id(settings: Settings) -> str:
    e = settings.embedder
    return f"hash-v1:{e.dim}" if e.model == "hash" else f"{e.model}@{e.revision}:{e.pooling}"


def corpus_hash(chunks: list[Chunk], settings: Settings, embedder_id: str) -> bytes:
    payload = {
        "format": 1,
        "embedder": embedder_id,
        "chunking": asdict(settings.chunking),
        "chunks": [asdict(c) for c in chunks],
    }
    return hashlib.sha256(json.dumps(payload, sort_keys=True, ensure_ascii=False, separators=(",", ":")).encode("utf-8")).digest()


def params_from_settings(settings: Settings, avgdl: float) -> IndexParams:
    s = settings.search
    return IndexParams(avgdl, s.dense_threshold, s.bm25_threshold, s.keyword_coverage, s.rrf_k, s.bm25_k1, s.bm25_b)


def build_index_bytes(settings: Settings, embedder: Embedder) -> bytes:
    chunks = collect_chunks(settings)
    texts = [chunk_index_text(c) for c in chunks]
    vectors = embedder.embed(texts) if texts else np.zeros((0, embedder.dim), np.float32)
    q, scales = quantize_int8(vectors)
    tokens = [tokenize(t) for t in texts]
    kw = build_keyword_index(tokens)
    records = [ChunkRecord(c.text, c.title, c.heading, c.url, c.source, c.project, c.kind, c.language, len(tok)) for c, tok in zip(chunks, tokens)]
    return write_index(
        vectors=q, scales=scales, records=records, keyword=kw,
        params=params_from_settings(settings, kw.avgdl),
        corpus_hash=corpus_hash(chunks, settings, embedder.id),
        flags=FLAG_SAMPLES if any(c.sample for c in chunks) else 0,
    )


def _f32(x: float) -> float:
    return float(np.float32(x))


def verify_fresh(settings: Settings) -> list[str]:
    path = settings.paths.index_out
    if not path.exists():
        return [f"{path} is missing. {REBUILD_HINT}"]
    ix = read_index(path.read_bytes())
    problems = []
    if ix.corpus_hash != corpus_hash(collect_chunks(settings), settings, expected_embedder_id(settings)):
        problems.append(f"the index is stale: the library, the published pages or the chunking settings changed. {REBUILD_HINT}")
    if ix.dim != settings.embedder.dim:
        problems.append(f"the index has {ix.dim} dims, rag.toml says {settings.embedder.dim}. {REBUILD_HINT}")
    s, p = settings.search, ix.params
    if (_f32(s.dense_threshold), _f32(s.bm25_threshold), _f32(s.keyword_coverage), s.rrf_k, _f32(s.bm25_k1), _f32(s.bm25_b)) != (
        p.dense_threshold, p.bm25_threshold, p.keyword_coverage, p.rrf_k, p.bm25_k1, p.bm25_b,
    ):
        problems.append("the search parameters in rag.toml differ from the index header. Run `uv run --project rag ottie-rag set-params` and commit the index.")
    return problems
```

```python
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

from .textnorm import tokenize


@dataclass(frozen=True)
class DenyTopic:
    id: str
    label: str
    phrases: tuple[tuple[str, ...], ...]


@dataclass(frozen=True)
class AllowRule:
    source: str
    term: str
    reason: str
    approved_on: str


@dataclass(frozen=True)
class DenyList:
    topics: tuple[DenyTopic, ...]
    allow: tuple[AllowRule, ...]


@dataclass(frozen=True)
class DenyHit:
    topic: str
    term: str


def load_denylist(path: Path) -> DenyList:
    raw = json.loads(Path(path).read_text(encoding="utf-8"))
    topics = tuple(
        DenyTopic(t["id"], t["label"], tuple(p for p in (tuple(tokenize(term, keep_stopwords=True)) for term in t["terms"]) if p))
        for t in raw["topics"]
    )
    allow = tuple(AllowRule(a["source"], " ".join(tokenize(a["term"], keep_stopwords=True)), a["reason"], a["approved_on"]) for a in raw.get("allow", []))
    return DenyList(topics, allow)


def _contains(tokens: list[str], phrase: tuple[str, ...]) -> bool:
    n = len(phrase)
    return any(tuple(tokens[i : i + n]) == phrase for i in range(len(tokens) - n + 1))


def match_denylist(dl: DenyList, text: str) -> list[DenyHit]:
    tokens = tokenize(text, keep_stopwords=True)
    hits = []
    for topic in dl.topics:
        for phrase in topic.phrases:
            if _contains(tokens, phrase):
                hits.append(DenyHit(topic.id, " ".join(phrase)))
    return hits
```

from __future__ import annotations

from datetime import date
from pathlib import Path
from typing import Literal

import yaml
from pydantic import BaseModel, ConfigDict, Field, ValidationError

from .corpus import load_library_files
from .denylist import load_denylist, match_denylist
from .frontmatter import split_frontmatter
from .index_format import FLAG_SAMPLES, read_index
from .settings import Settings
from .textnorm import tokenize


class SuggestedSource(BaseModel):
    title: str
    url: str | None = None
    source: str


class SuggestedEntry(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: str = Field(pattern=r"^[a-z0-9-]+$")
    question: str = Field(min_length=1, max_length=300)
    language: Literal["en", "fr"] = "en"
    order: int = 0
    audience: list[str] = []
    answer: str | None = None
    sources: list[SuggestedSource] = []
    generated_on: date | None = None
    model: str | None = None
    reviewed_on: date | None = None
    sample: bool = False


def load_suggested(settings: Settings) -> list[tuple[Path, SuggestedEntry]]:
    folder = settings.paths.suggested
    if not folder.exists():
        return []
    return [(p, SuggestedEntry.model_validate(yaml.safe_load(p.read_text(encoding="utf-8")))) for p in sorted(folder.glob("*.yaml"))]


def _rel(settings: Settings, path: Path) -> str:
    return path.resolve().relative_to(settings.root).as_posix()


def _first_line(text: str, phrase: str) -> int:
    want = phrase.split()
    for number, line in enumerate(text.splitlines(), start=1):
        tokens = tokenize(line, keep_stopwords=True)
        if any(tokens[i : i + len(want)] == want for i in range(len(tokens) - len(want) + 1)):
            return number
    return 1


def _is_draft(path: Path, text: str) -> bool:
    if path.suffix not in (".md", ".mdx"):
        return False
    try:
        meta, _ = split_frontmatter(text)
    except ValueError:
        return False
    return meta.get("status") == "draft"


def run_checks(settings: Settings, release: bool = False, today: date | None = None) -> list[str]:
    today = today or date.today()
    problems: list[str] = []
    library_paths = {p.resolve() for p in settings.paths.library.glob("*.md")} if settings.paths.library.exists() else set()

    try:
        library = load_library_files(settings)
    except ValidationError as err:
        return [f"library frontmatter is invalid: {err}"]
    for f in library:
        if f.meta.approved_on is None and not f.meta.sample:
            problems.append(f"{f.source}: approved_on is missing. Only Din sets it, after reviewing the entry in a PR.")
        if f.meta.approved_on and f.meta.approved_on > today:
            problems.append(f"{f.source}: approved_on {f.meta.approved_on} is in the future.")
        if release and f.meta.sample:
            problems.append(f"{f.source}: sample entries cannot ship in a release. Remove it, or make it a real entry Din approves.")

    for path, entry in load_suggested(settings):
        rel = _rel(settings, path)
        if entry.reviewed_on is None and not entry.sample:
            problems.append(f"{rel}: the suggested answer is not reviewed by Din (reviewed_on is empty).")
        if release and entry.sample:
            problems.append(f"{rel}: sample suggested questions cannot ship in a release.")

    dl = load_denylist(settings.paths.denylist)
    allowed = {(a.source, a.term) for a in dl.allow}
    seen: set[Path] = set()
    for pattern in settings.scan_globs:
        for path in sorted(settings.root.glob(pattern)):
            if path in seen or not path.is_file():
                continue
            seen.add(path)
            text = path.read_text(encoding="utf-8")
            if path.resolve() not in library_paths and _is_draft(path, text):
                continue
            rel = _rel(settings, path)
            for hit in match_denylist(dl, text):
                if (rel, hit.term) in allowed:
                    continue
                problems.append(f"{rel}:{_first_line(text, hit.term)}: mentions a deny-list topic ({hit.topic}: '{hit.term}'). Remove it, or ask Din to add an allow rule in site/src/lib/ask/denylist.json.")

    if release and settings.paths.index_out.exists() and read_index(settings.paths.index_out.read_bytes()).flags & FLAG_SAMPLES:
        problems.append(f"{_rel(settings, settings.paths.index_out)}: the index contains sample entries; rebuild it after removing them.")
    return problems

```python
from __future__ import annotations

from pathlib import Path
from typing import Literal

import yaml
from pydantic import BaseModel, ConfigDict, Field

from .settings import Settings


class Turn(BaseModel):
    model_config = ConfigDict(extra="forbid")
    question: str = Field(min_length=1, max_length=300)
    answer: str = Field(min_length=1)


class GoldenItem(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: str = Field(pattern=r"^[a-z0-9-]+$")
    question: str = Field(min_length=1, max_length=300)
    language: Literal["en", "fr"]
    expected_sources: list[str] = Field(min_length=1)
    reference_answer: str
    project: str | None = None
    history: list[Turn] = []
    sample: bool = False


class AdversarialItem(BaseModel):
    model_config = ConfigDict(extra="forbid")
    id: str = Field(pattern=r"^[a-z0-9-]+$")
    question: str = Field(min_length=1, max_length=300)
    language: Literal["en", "fr"]
    category: Literal["deny_list", "off_topic", "injection", "unknown"]
    expect: Literal["decline", "redirect", "refuse_injection", "dont_know"]
    sample: bool = False


def _load(path: Path, model: type[BaseModel]) -> list:
    raw = yaml.safe_load(Path(path).read_text(encoding="utf-8")) or {}
    if raw.get("version") != 1:
        raise ValueError(f"{path}: version must be 1")
    items = [model.model_validate(x) for x in raw.get("items", [])]
    seen: set[str] = set()
    for item in items:
        if item.id in seen:
            raise ValueError(f"{path}: duplicate id {item.id}")
        seen.add(item.id)
    return items


def load_golden(path: Path) -> list[GoldenItem]:
    return _load(path, GoldenItem)


def load_adversarial(path: Path) -> list[AdversarialItem]:
    return _load(path, AdversarialItem)


def retrieval_query(question: str, history: list[Turn]) -> str:
    return f"{history[-1].question}\n{question}" if history else question


def all_retrieval_queries(settings: Settings) -> list[str]:
    from .checks import load_suggested

    queries = [retrieval_query(g.question, g.history) for g in load_golden(settings.paths.golden)]
    queries += [a.question for a in load_adversarial(settings.paths.adversarial)]
    queries += [s.question for _, s in load_suggested(settings)]
    return list(dict.fromkeys(queries))
```

```python
from __future__ import annotations

from dataclasses import asdict, dataclass, field

from .denylist import load_denylist, match_denylist
from .evalsets import load_adversarial, load_golden, retrieval_query
from .index_format import IndexData, QueryCache
from .search import search
from .settings import Settings


@dataclass(frozen=True)
class ItemResult:
    id: str
    recall: float
    answerable: bool
    top_dense: float | None
    retrieved_sources: list[str]


@dataclass
class RetrievalReport:
    recall_at_6: float
    golden_answerable_rate: float
    deny_classifier_rate: float
    unknown_dont_know_rate: float
    off_topic_gate_rate: float
    items: list[ItemResult] = field(default_factory=list)
    failures: list[str] = field(default_factory=list)

    def to_json(self) -> dict:
        return asdict(self)


@dataclass(frozen=True)
class ThresholdSuggestion:
    min_golden: float | None
    max_negative: float | None
    suggested: float | None
    separable: bool


def _rate(values: list[bool]) -> float:
    return sum(values) / len(values) if values else 1.0


def run_retrieval_eval(settings: Settings, index: IndexData, cache: QueryCache) -> RetrievalReport:
    failures: list[str] = []
    items: list[ItemResult] = []
    for g in load_golden(settings.paths.golden):
        query = retrieval_query(g.question, g.history)
        qvec = cache.get(query)
        if qvec is None:
            failures.append(f"{g.id}: no cached embedding for {query!r}; run `pnpm --dir site ask:index`")
            continue
        r = search(index, qvec, query, g.project)
        sources = list(dict.fromkeys(index.records[h.chunk].source for h in r.hits))
        recall = len(set(g.expected_sources) & set(sources)) / len(g.expected_sources)
        items.append(ItemResult(g.id, recall, r.answerable, r.top_dense, sources))
        if recall < 1.0:
            failures.append(f"{g.id}: expected {g.expected_sources}, got {sources}")

    dl = load_denylist(settings.paths.denylist)
    deny, unknown, off_topic = [], [], []
    for a in load_adversarial(settings.paths.adversarial):
        if a.category == "deny_list":
            ok = bool(match_denylist(dl, a.question))
            deny.append(ok)
            if not ok:
                failures.append(f"{a.id}: the deny-list classifier does not catch {a.question!r}")
            continue
        qvec = cache.get(a.question)
        if qvec is None:
            failures.append(f"{a.id}: no cached embedding for {a.question!r}")
            continue
        gated = not search(index, qvec, a.question).answerable
        (unknown if a.category == "unknown" else off_topic if a.category == "off_topic" else []).append(gated)

    return RetrievalReport(
        recall_at_6=sum(i.recall for i in items) / len(items) if items else 0.0,
        golden_answerable_rate=_rate([i.answerable for i in items]),
        deny_classifier_rate=_rate(deny),
        unknown_dont_know_rate=_rate(unknown),
        off_topic_gate_rate=_rate(off_topic),
        items=items,
        failures=failures,
    )


def _top_dense(index: IndexData, cache: QueryCache, query: str, project: str | None = None) -> float | None:
    qvec = cache.get(query)
    return None if qvec is None else search(index, qvec, query, project).top_dense


def suggest_threshold(settings: Settings, index: IndexData, cache: QueryCache) -> ThresholdSuggestion:
    golden: list[float] = []
    for g in load_golden(settings.paths.golden):
        value = _top_dense(index, cache, retrieval_query(g.question, g.history), g.project)
        if value is not None:
            golden.append(value)
    negative: list[float] = []
    for a in load_adversarial(settings.paths.adversarial):
        if a.category in ("unknown", "off_topic"):
            value = _top_dense(index, cache, a.question)
            if value is not None:
                negative.append(value)
    if not golden or not negative:
        return ThresholdSuggestion(min(golden, default=None), max(negative, default=None), None, False)
    lo, hi = min(golden), max(negative)
    separable = lo > hi
    return ThresholdSuggestion(lo, hi, round((lo + hi) / 2, 3) if separable else round(lo - 0.02, 3), separable)
```

def _post_json(url: str, token: str, body: dict) -> dict:
    req = urllib.request.Request(url, data=json.dumps(body).encode(), headers={"Authorization": f"Bearer {token}", "Content-Type": "application/json"}, method="POST")
    with urllib.request.urlopen(req, timeout=30) as resp:
        return json.loads(resp.read())


def remote_embed(texts: list[str], account_id: str, token: str, post_json: Callable[[str, str, dict], dict] = _post_json) -> tuple[np.ndarray, str | None]:
    out = post_json(_URL.format(account=account_id), token, {"text": texts})
    if not out.get("success"):
        raise RuntimeError(f"Workers AI error: {out.get('errors')}")
    result = out["result"]
    return np.asarray(result["data"], dtype=np.float32), result.get("pooling")


@dataclass
class AgreementReport:
    min_cosine: float
    mean_cosine: float
    pooling: str | None
    ranking_overlap: float | None
    passed: bool
    details: list[str] = field(default_factory=list)


def _unit(v: np.ndarray) -> np.ndarray:
    n = np.linalg.norm(v, axis=-1, keepdims=True)
    return v / np.where(n > 0, n, 1)


def run_agreement(settings: Settings, local: Embedder, remote: Callable[[list[str]], tuple[np.ndarray, str | None]], index: IndexData | None) -> AgreementReport:
    details: list[str] = []
    a = _unit(local.embed(AGREEMENT_TEXTS))
    b, pooling = remote(AGREEMENT_TEXTS)
    b = _unit(b)
    cos = np.sum(a * b, axis=1)
    for text, c in zip(AGREEMENT_TEXTS, cos):
        if c < 0.99:
            details.append(f"cosine {c:.4f} for {text!r}")
    if pooling is not None and pooling != settings.embedder.pooling:
        details.append(f"Workers AI reports pooling {pooling!r}, rag.toml uses {settings.embedder.pooling!r}")
    overlap = None
    if index is not None:
        queries = [retrieval_query(g.question, g.history) for g in load_golden(settings.paths.golden)]
        lv, (rv, _) = local.embed(queries), remote(queries)
        shares = []
        for q, x, y in zip(queries, lv, rv):
            left = {h.chunk for h in search(index, x, q).hits}
            right = {h.chunk for h in search(index, y, q).hits}
            shares.append(len(left & right) / max(len(left), 1))
        overlap = float(np.mean(shares)) if shares else None
        if overlap is not None and overlap < 5 / 6:
            details.append(f"top-6 overlap {overlap:.3f} is below 5/6")
    return AgreementReport(float(cos.min()), float(cos.mean()), pooling, overlap, not details, details)
