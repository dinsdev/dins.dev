# Holding page

A single static page that says dins.dev is under construction, shown at `dins.dev` until the real site (M0 to M5) replaces it. It uses the brand tokens, the lockup, Fraunces and Instrument Sans, and Ottie's idle loop as a CSS sprite. No JavaScript, no build step at serve time.

| Path | What it is |
|---|---|
| `public/index.html`, `public/holding.css` | The page, written by hand |
| `public/assets/` | Generated by `build.py` from `brand/`: tokens, lockups, Ottie's idle sheet, font subsets with their licences. Do not edit. |
| `public/*.png`, `favicon.*`, `site.webmanifest` | Generated icons, copied to the root where browsers look for them |

## Rebuild the assets

```bash
uv run --no-project --with fonttools --with brotli python holding/build.py
```

Rerun after any change to the tokens, logos, fonts or Ottie sheets.

## Preview

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory holding/public
```

Then open http://127.0.0.1:8766. Also available as the `holding` entry in `.claude/launch.json`.

The page sets `noindex`, so search engines skip it until launch. Remove this folder when the real site goes live.
